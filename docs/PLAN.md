# GAP Project Plan

This repository contains the implementation of the GAP project.

## Core priorities

1. Gate 1: text → Nemotron → validated JSON → database → web → outcome → adherence percentage.
2. Complete all Kademe 1 functionality before the 19 October 2026 feature freeze.
3. After the freeze, only bug fixes and reliability work are accepted.
4. Web remains the primary demo and must work without ESP32.
5. ESP32 is an additional experience with a hard integration checkpoint.
6. API and AI schemas remain centralized and versioned.
7. Student-study data remains anonymous and separate from demo seed data.

## Delivery

Target delivery: 29 October 2026.
